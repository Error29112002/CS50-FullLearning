### Pacing notes
- **Weeks 0–2 — fast review.** I've done these before. Skim the lecture at 1.5×, then re-solve the problem sets from scratch to bring C back.
- **Weeks 3–5 — full attention.** Recursion, pointers, `malloc`, linked lists and hash tables. This is where most people get stuck, so it gets the most time.
- **Weeks 6–9 — moderate.** Python, SQL and web feel familiar after C. Start picking a final project idea during week 6.
- **Check the gradebook first.** Some earlier submissions may still count this year, so I may not need to redo them.
- **Falling behind?** Cut the optional "more comfortable" variants (e.g. `mario-more`, `credit`) before cutting core psets.
